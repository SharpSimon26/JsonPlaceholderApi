# JSONPlaceholder Api

Esercizio Minimal Api in C#

## Compatibilità

Il progetto fa uso di:
- .NET 10
- MS SQL Server 2025

## Esecuzione

``` Bash
dotnet run --project src/JsonPlaceHolder.Api
```

## Unit Tests

``` Bash
dotnet test
```

## Tabelle e dati

Script sql ```jph-users-posts.sql``` con tabelle e dati presente in dataset
